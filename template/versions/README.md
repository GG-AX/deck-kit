# versions — 구버전 코드

**라이브는 `presentation/`, 구버전은 여기.** 라이브와 같은 사본은 두지 않는다.

| 버전 | 폴더 | 내용 |
| --- | --- | --- |

## 구버전 남기는 법

1. `presentation/`을 **고치기 직전에** 지금 상태의 HTML·CSS·JS를 `vN_<이름>/`으로 복사한다(N = 지금 라이브 번호).
2. 복사한 HTML 안의 css·js 경로를 `../versions/vN_<이름>/assets/...`로 바꾸고, `<head>`에 `<base href="../../presentation/">`를 넣는다 — 그림·영상은 라이브의 것을 함께 쓴다.
3. 그다음 `presentation/`을 고친다 → versions에는 항상 라이브보다 이전 상태만 남는다. 오래된 버전을 지울지는 그때 사용자에게 확인한다.

- 코드 기록용이다. 그림·영상이 나중에 바뀌거나 지워지면 화면은 완전히 재현되지 않는다.
- 구버전을 열어 발표자 스크립트를 저장하지 않는다.
