# versions — 구버전 코드

**라이브는 `presentation/`, 구버전은 여기.** 라이브와 같은 사본은 두지 않는다.

| 버전 | 폴더 | 내용 |
| --- | --- | --- |

## 구버전 남기는 법

1. 피드백을 반영하려고 **아무것도 고치기 전에** 덱 폴더에서 `python <deck-kit>\tools\snapshot.py vN_<이름> "한 줄 설명"`(N = 지금 라이브 번호). 한 번이라도 고친 뒤에 백업하면 사본이 옛 덱과 어긋난다.
   - 하는 일: 덱 HTML·`assets`의 CSS·JS·`work`와 `tools`의 덱 스크립트를 `vN_<이름>/`에 복사하고, 경로를 고치고(`<base href="../../presentation/">` — 그림·영상·글꼴은 라이브 것을 함께 씀), 아래 표에 줄을 더한다.
2. 그다음 `presentation/`을 고친다 → versions에는 항상 라이브보다 이전 상태만 남는다. 오래된 버전을 지울지는 그때 사용자에게 확인한다.

- 코드 기록용이다. 그림·영상이 나중에 바뀌거나 지워지면 화면은 완전히 재현되지 않는다. 안 쓰는 파일을 정리한 뒤에는 `lint.py`로 백업이 쓰는 파일이 남아 있는지 확인한다.
- 구버전을 열어 발표자 스크립트를 저장하지 않는다.
